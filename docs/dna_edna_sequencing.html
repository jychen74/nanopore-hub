DNA / eDNA Kit 選擇

本頁用於 DNA / eDNA / amplicon 樣本的 ONT kit 選擇。
建庫前請先確認 DNA / eDNA 核酸 QC 標準，實際操作步驟請見 DNA / eDNA 建庫 protocol。

重要

Kit 與 flow cell 的原廠定價請使用 ONT 產品選擇器 查詢；本頁只保留選擇邏輯。

Kit 選擇流程

目標是 16S/ITS 微生物群落鑑定？

  • 是 → SQK-MAB114.24（16S rRNA / ITS amplicon，最多 24 samples）
  • 否 → 繼續判斷 DNA / eDNA 建庫方式

需要多樣本 multiplex（barcoding）？

是 → DNA 量是否充足（>= 200 ng / sample）？

  • 是 → 高品質 gDNA（HMW fragment，A260/A230 >= 2.0）？
    • 是 → SQK-NBD114.24（native barcoding，最長讀長，PCR-free）
    • 否 → SQK-RBK114.24（rapid barcoding，適合環境 / 糞便 / 低品質 DNA）
  • 否（DNA 量不足）→ DNA fragment 是否 >= 4 kb，且可取到 1-5 ng？
    • 是 → SQK-RPB114.24（Rapid PCR Barcoding，低量 eDNA）
    • 否 → 重新提取、濃縮或改變樣本策略

否（單樣本）→

  • 需要最大輸出量、最長讀長或保留 methylation → SQK-LSK114
  • 需要最快速 exploratory sequencing → SQK-RAD114

依樣本類型快速判斷

樣本 / 目的 優先 kit 備註
高品質 gDNA，多樣本 SQK-NBD114.24 PCR-free，讀長較佳，對 input quality 較敏感
環境、糞便、抑制物風險較高 SQK-RBK114.24 快速、操作較簡單，適合常規 metagenomics
水體過濾膜、低量 eDNA SQK-RPB114.24 PCR-based；input DNA 仍需 >= 4 kb
單樣本、高品質 gDNA、最大輸出 SQK-LSK114 適合 assembly、SV、methylation
單樣本、最快速測試 SQK-RAD114 適合 exploratory run，不適合 multiplex
16S / ITS 群落鑑定 SQK-MAB114.24 下游可搭配 EPI2ME wf-16s
