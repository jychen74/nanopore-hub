RNA / cDNA 定序

本頁整理 ONT RNA / cDNA sequencing kits 的選擇邏輯。
目前定位為 kit selection 與 QC decision page，不是 bench-side step-by-step SOP。

重要

建庫前請先確認 RNA / cDNA 核酸 QC 標準，不要直接套用 DNA / gDNA 的 QC cutoff。 Kit、flow cell 與原廠定價請使用 ONT 產品選擇器 查詢。

使用時機

RNA / cDNA 定序不應直接併入 gDNA metagenomics kit 表格，因為 input QC、flow cell、library chemistry 與分析目標都不同。

目標 優先考慮 主要理由
多樣本 transcript sequencing、splice variants、fusion transcripts SQK-PCB114.24 cDNA-PCR barcoding，最多 24 samples，使用 R10.4.1 flow cell
單樣本 cDNA transcript sequencing SQK-PCS114 SQK-PCB114.24 的 single-sample counterpart
native RNA、RNA modification、避免 RT/PCR amplification bias SQK-DRB004.24 Direct RNA barcoding，保留 native RNA 訊號，但流程較長且需 RNA flow cell
單樣本 native RNA SQK-RNA004 SQK-DRB004.24 的 single-sample counterpart
提示

若目標是一般病原檢測或多樣本 RNA/cDNA screening，建議先以 SQK-PCB114.24 作為主流程。
若目標包含 RNA modification、native RNA molecule 特性、或明確需要避免 RT/PCR bias，再考慮 SQK-DRB004.24。

Kit 選擇流程

是否需要 native RNA 訊號？

  • 是，例如 RNA modification、poly(A) length、避免 RT/PCR bias
    • 需要 multiplex：SQK-DRB004.24
    • 單一樣本：SQK-RNA004
  • 否，主要是 transcript identification / quantification / isoform / fusion transcript
    • 需要 multiplex：SQK-PCB114.24
    • 單一樣本：SQK-PCS114
警告

Direct RNA workflow 不等於「比較簡單」。
SQK-DRB004.24 需 RNA flow cell，library preparation 約 360 min，且對 RNA integrity、poly(A)+ enrichment 或 poly(A)-tailed input 的要求較高。
